# Grant application readiness pack

Prepare a specific funding application so the user can review it before anyone submits. Do not use this to search for new prizes or grants — that is Prize and funding watch. Start only after a particular call has been chosen.

## 1. Read the actual call
Open the official guidance, form, and eligibility rules. Write down only what those sources support, labelled **VERIFIED** or **INFERRED**:
- who may apply and any legal-entity, location, or career-stage limits
- deadlines and required documents
- budget, co-funding, or match-funding rules
- what the funder says it wants to achieve
- how and where the application is submitted

Do not invent officer names, dates, or criteria.

## 2. Test fit
Map the proposed project — its evidence, aims, activities, and beneficiaries — to the funder's stated mission and criteria. Flag go/no-go blockers (ineligible applicant type, missing partner, unmet co-funding, a document that does not exist yet). If fit is weak, say so before drafting at length.

## 3. Assemble the pack
Prepare, as the call requires:
- a proposal outline aligned to the funder's questions or themes
- a budget and co-funding check (reference a sourced cost model when one exists)
- a document checklist showing what is ready, missing, or waiting on someone else
- open questions and assumptions the user must confirm

## 4. Stop at internal review
Hand over a reviewable application pack. Do not submit the application, accept funder conditions, or contact the funder unless the user explicitly asked for that step.
