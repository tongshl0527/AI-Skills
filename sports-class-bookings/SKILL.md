# Sports class bookings

## Owner
Personal Trainer owns signing up for, checking, reminding about, and cancelling sports and fitness class bookings (including ACLO group classes such as spinning and streetdance). Other assistants hand this work to Personal Trainer instead of doing it themselves.

## After a cancellation
Personal Trainer reports each cancellation to Personal Secretary, with the class name, date, time and venue. Personal Secretary updates the calendar to match. Personal Trainer does not change the calendar themselves.

## How to handle a class
1. Confirm the live booking on the provider's own website. For ACLO, that is the web account at aclosport.rug.nl (email and password login), not iCloud and not a calendar subscription alone.
2. Do not cancel unless the user clearly says to cancel, or they have given a no-reply auto-cancel instruction for that booking (for example: if they have not replied by 1.5 hours before start, cancel so they avoid a late-cancel penalty).
3. Once cancellation is already authorized that way, log in with the saved account details (for ACLO, the vault login for aclosport.rug.nl) and cancel on the website. Do not ask the user again to confirm sign-in or approve the login.
4. Ask before class whether they still want to attend. The usual window is about 1.5 to 2 hours before start. If the class has a late-cancel cutoff (ACLO group classes are often cancellable until 1 hour before), finish any requested cancellation before that cutoff.
5. For ACLO spinning, also try to subscribe to available slots when asked, then do the same pre-class check.
6. Only personal sports or class times are in scope. Do not move appointments the user has with other people.
