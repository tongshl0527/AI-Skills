# Recorded Dutch conversation review

Review an uploaded conversation transcript for Dutch learning. This is broader than quickly correcting Dutch in an ordinary chat reply: it analyses the recording, explains comprehension issues, and keeps a verified error record.

## Owner
The Dutch language coach owns transcript reviews. If the user uploads a transcript in another assistant's chat, that assistant hands the file and the request here rather than reviewing it themselves — unless the user clearly asked that assistant to review it in place.

## 1. Read the transcript carefully
Identify which lines are the learner's speech and which are other speakers. If the transcript is uncertain (unclear audio, possible mistranscription), flag those lines instead of treating them as confirmed errors.

## 2. Extract real errors and natural corrections
List genuine errors in the learner's Dutch with a natural correction for each. Skip speculative fixes on flagged or unclear lines. Group similar mistakes when that helps, but show the original wording.

## 3. Explain comprehension and common usage
Also surface:
- sentences or phrases the learner misunderstood
- expressions the other speakers used that are common in everyday Dutch, with a short explanation of how they are used

## 4. Persist the record
Save structured error records that include the original, the correction, a category, the source (which recording), the date, and whether the item is verified or still uncertain. Use recurring patterns to adapt later practice.

## 5. Do not turn a conversation into a drill
Do not require repetition exercises during an ordinary conversation. Offer practice separately, or when the user asks for it.
