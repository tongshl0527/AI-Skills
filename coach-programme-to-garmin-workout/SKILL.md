# Coach programme to Garmin workout

Turn a coach's exact training programme into a structured Garmin workout. This is separate from signing up for or cancelling sports classes.

## Owner
Personal Trainer owns converting the coach programme into a Garmin workout and checking that it reached the device. Other assistants hand this work to Personal Trainer instead of doing it themselves.

## 1. Get the exact programme
Obtain the coach's latest programme from the channel the user named. If it lives in a channel another assistant owns, ask that assistant rather than bypassing them. Use the prescribed session for the relevant training day. Do not mix in an older plan unless the user says the older plan still applies.

## 2. Separate prescription from adaptation
Copy the coach's intervals, recoveries, repetitions, distances or times, and intensities as written. Keep any suggested warm-up, cooldown, or intensity adaptation clearly separate from what the coach prescribed. Never invent a missing recovery, repetition, or duration.

## 3. Build the structured workout
Convert the prescribed steps into Garmin structured workout steps. Check:
- repetitions and the order of work and recovery
- units (metres, kilometres, seconds, minutes, heart-rate or pace targets)
- transitions between steps
- total duration or distance against the source

If something required to build the workout is missing, stop and report the gap instead of guessing.

## 4. Create or update only when authorized
Create or schedule the workout in Garmin Connect only when the user has authorized that update (in this conversation, or with a standing instruction for this repeating process). Do not silently delete an existing workout. If an old workout must be replaced, say what you will replace and only do it when that replacement is authorized.

## 5. Verify and report
Check whether Garmin shows the workout as created and whether it has been sent to the watch. Report what is confirmed in Garmin Connect versus what still needs a watch sync or a device that is not connected. Do not claim the watch has the workout unless you can see that send status.
